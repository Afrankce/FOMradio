# A 方案的 Beam 配置响应诊断

本实验是探索性分析。U6G 测试结果此前已经查看，不能把本文件称为预注册或未接触测试集上的确认性分析。

## 问题

在冻结的 A 检查点上，固定环境和 Matérn 源随机场，仅改变目标配置时，预测的功率图变化是否与真实变化一致？这个问题检验配置响应，不直接证明信息解耦或判定性能下降的唯一原因。

## 固定配置

- 模型：原始 A 的 seed 42、43 最佳验证检查点；不重新训练。检查点哈希、训练种子及选中步数必须记录。
- 数据：原 160 个 held-out 测试场景；6.7 GHz；8×8 和 32×32；角度 −28、−21、−14、−7、0、7、14、21°。训练仅包含 8×8 的 −14、0、14°。不提供辅助 Radio Map 或目标 Radio Map 给推理。
- 每个场景使用 4 次噪声抽样；同一模型、场景、抽样下，所有配置严格使用同一个初始场。抽样种子与模型训练种子独立；四次抽样不是四次训练。
- 模型原有的数据预处理、256×256 输入、8 步 Euler、FP16 前向和下采样到 128×128 均与现有测试保持一致。噪声随机流按配对诊断重新设置，因此这不是对原测试逐查询随机样本的复现。
- 标签只在对应场景的所有目标配置推理完成后打开。只在两个标签都满足 −300 < 值 < 0 dB 的交集上计算指标。空交集视为错误，不允许悄悄丢弃场景。

## 比较

以 0° 为基准，对 8×8 分别考察已见角度（−14、+14°）、未见角度插值（−7、+7°）和外推（−28、−21、+21°）。对八个角度逐一比较同角度 8×8 与 32×32，并分别汇总训练见过/未见过的角度。补充在 32×32 内以 0° 为基准的角度响应。32×32 在训练中均未见过。

## 指标和汇总

对每一对图、场景和噪声抽样，设预测变化 Δŷ=ŷ₂−ŷ₁、真实变化 Δy=y₂−y₁，以 dB 表示：

1. **Response MAE**：有效交集上的 mean(|Δŷ−Δy|)，越小越好。
2. **真实/预测变化强度**：mean(|Δy|) 与 mean(|Δŷ|)，单独衡量变化幅度，不等同于方向正确。
3. **零变化基线**：令 Δŷ=0，其误差恰为 mean(|Δy|)。
4. **Beam 差值基线**：使用与输入一致地裁剪到 [−300,0] dB 的目标 Beam 差值 ΔB，报告 mean(|ΔB−Δy|)。Beam 是自由空间信息，基线比较仅为描述性参考。
5. **Pearson 相关系数**：交集上的 Δŷ 与 Δy 的空间相关；零方差时记录为空并汇报数量。

每个场景内对角度和四次抽样等权平均，然后对场景等权平均。两个训练种子分别报告，也报告先按场景对两个固定检查点取均值的结果；区间只对场景作 95% percentile bootstrap，不表示训练种子层面的不确定性。四次噪声抽样也不作为独立场景。报告保留每种配置对和每个场景的明细。

## 核验与边界

- 首先复跑原验证集的四个查询，用原本随机流与已保存验证 MAE 核对；再检查相同条件和相同初始场的重复预测一致。初次尝试发现当前环境复现归档 MAE 的最大差值约 0.000652 dB，超过原脚本的 0.0001 dB 阈值；原始评估代码本身也出现相同偏差。为继续探索性诊断，新增当前环境下与原始评估函数逐像素一致性检查，并将历史 MAE 允许差值调整为 0.01 dB；保留两项误差，不声称跨环境逐位复现。具体原因仍未确定。
- 同一个条件和源放在 batch 的偶数与奇数位置时，发现可复现但很小的差异；该现象在 FP16 和禁用 autocast 的单步检查中均存在，成因未确定。诊断时把每个配置在四元素 batch 中复制一次，只取固定的第 0/2 位，并核对相同配置在这两个位置以及不同邻居条件下的输出一致，避免把已观察到的位置差异混入配对响应。此为检查后记录的实现变更，不改变模型权重。
- 对合成数组验证误差、交集掩膜与零变化基线，逐项检查输入与预测有限且维度正确。
- 真实、预测和 Beam 差值为 dB 差；不解释为电场复振幅或线性功率差。
- 响应较弱、形状错误或基线优势只是诊断现象；不能仅凭它区分训练覆盖、表示耦合、归一化和物理信息缺失，也不能证明严格的物理可辨识性。
