# U6G 无辅助无线电图：A 与结构化传播 C 的实验计划

> **状态：研究设计草案。** 按用户要求保留 A 的原方案，C 更新为“环境 FNO + 解析阵列激励 + 相干组合 + Beam 引导 Matérn 与 Flow Matching”。C 的速度网络仍不直接接收 Beam Map。前一版留存于 `2026-10-31-u6g-ac-beam-matern-v2.md`，更早版本为 `2026-10-31-u6g-ac-beam-matern-v1.md`。本计划的 A/C 不是旧 B/C 结构实验或 T0/T2/T3。新 C 尚未实现或训练；执行前冻结清单、参数、比较指标及选择规则。此前已查看部分 U6G 测试场景和历史结果，首轮属于探索性研究。

**Question:** 在不输入辅助或目标 Radio Map 的条件下，将环境 FNO、解析阵列激励、Beam 引导 Matérn 源和 Flow Matching 结合的 C，能否在未见阵列及场景上达到或超过 A？

**Design:** A 完全沿用上一版：“目标 Beam 直接输入速度网络 + 固定多尺度 Matérn 源”。C 新增独立环境 FNO，输出复数潜在传播基；由目标阵列配置解析计算复数激励并相干组合形成预测均值，再以此均值和 Beam 引导的 Matérn 噪声作为 FM 源。C 的速度网络不直接接收 Beam。数据、训练更新次数与评估协议保持一致；C 比 A 多一个环境网络、两个采样标量和均值监督项。A/C 从头训练并配对共享部分的初始化、样本、时间与随机噪声；这是整体方案比较，不能将差异单独归因于噪声、物理结构或条件输入。

**Data:** 优先使用官方 Multi-config Radiomap/U6G 数据；以场景为分组单位。沿用原项目 560/80/160 的实际场景清单，并在新 manifest 中核对划分、物理角度及对应文件。首轮不混用实验性重生成标签。

**Primary analysis:** 固定 6.7 GHz，在训练未出现的 `32×32` 阵列、但训练出现过的三个角度上，计算每场景 MAE 的配对差值 `C−A`；测试场景同时未在训练中出现。按场景进行配对 bootstrap，并逐训练种子报告结果。

**Decision rule:** 主比较维持探索性的优势门槛：C 相比 A 的平均 MAE 至少降低 `0.1 dB`，场景配对 bootstrap 的双侧 95% 区间上限小于 0，且 3 个训练种子至少 2 个改善。另报告一个预设、探索性的“接近 A”参考：`Δ=C−A` 的单侧 95% 场景 bootstrap 上限小于 `0.1 dB`；据此只能说在这批场景、所用种子及假定容差内未观察到超过该幅度的退化，不能仅凭区间跨 0 宣称等价。`0.1 dB` 是暂定工程门槛，不是普适标准；场景 bootstrap 不覆盖训练种子的完整不确定性。

## 2. A 保持不变，C 的输入路径更新

| 项目 | A：原固定多尺度 Matérn | C：结构化传播 + Beam 引导源 |
|---|---|---|
| 环境与 Tx 输入速度网络 | 使用 | 使用 |
| 目标 beam 直接输入速度网络 | 使用 | **不使用** |
| 目标 beam 构造噪声源 | 不使用 | **使用** |
| 阵列配置与复数激励 | 不另设解析分支 | **解析生成激励系数** |
| 直接读取目标阵列规格、角度与码本元数据 | 无；配置影响体现在目标 Beam Map 中 | 有；用于解析复数激励 |
| 独立环境 FNO 和结构化预测均值 | 无 | **有，环境 FNO 不接收 Beam 或阵列规格** |
| 目标/辅助 radio map 作为推理输入 | 无 | 无 |
| FM 速度网络 | 原 U-shaped FNO + AP | 共同骨架和初始化；Beam 条件置零 |
| 源状态 | `GP(0,C_MS)`，与目标 beam 无关 | `x0=mu(H,Tx,f,array,angle)+sigma*z_B` |
| 新增可训练参数 | 无 | 环境 FNO、复数输出头和两个采样标量 `a,d` |
| 损失 | 原 FM + 两级 Haar | 相同 FM + Haar，再加结构化均值监督 |
| 训练更新、数据与评价 | 不变 | 相同；显式记录额外参数与计算 |

两组均使用目标配置的 Beam Map，但路径不同：A 直接输入速度网络；C 的 Beam Map 只用于计算噪声概率，目标配置中的阵列位置、频率和波束角度另用于解析激励。C 的环境 FNO 不接收 Beam、概率图、阵列大小或角度；FM 速度网络不直接接收 Beam、概率图、阵列规格或角度，但可通过 `x_t` 间接感受到结构化均值和 Beam 条件噪声。C 为**连续概率加权**，不进行离散锚点采样或新增真实测量。相干头在固定环境、频率和参考阵面下具有对复数激励的线性结构；FM 后的最终输出不保证该性质。新增环境网络与监督意味着 A/C 仅支持整体方案比较；隔离各组成部分需后续另做消融，不纳入本轮。

为保持用户要求的 A 不变，本轮不向 A 额外输入阵列规格和复数码本。C 使用目标配置元数据构造解析激励，A 只通过功率型 Beam Map 接触配置；后者未必足以恢复复数相位，因此**两组可用的信息量不能简单视为相同**。这些元数据是已知目标配置而非无线电观测，但若 C 更好，不能排除其额外物理输入的贡献；正文需同时报告这一条件差异和计算成本。

## 3. 数据接口与防泄漏合同

单条记录标识为 `(scene_id, frequency_hz, Nx, Ny, physical_angle_deg, beam_id)`，物理角度依据配置映射核对；不能把不同阵列的相同 beam index 默认当作相同物理角度。

系统允许使用建筑高度 `H`、固定 Tx 编码、**当前目标配置**的 beam map `B`、配置元数据、生成时刻及噪声。目标 radio map `Y` 和标签有效掩膜只用于训练损失或离线评分，不进入条件编码器、环境 FNO、源概率分支和推理 API。预测端不接受 `target_path`、目标有效掩膜或任何辅助 radio-map 路径。A 内部条件保持 `c_A=[Tx,H,B,0,0,0]`。C 环境 FNO 接收 `[Tx,H,F]`，FM 速度网络接收 `c_C=[Tx,H,F,0,0,0]`，其中 `F=log(f/6.7e9)` 广播到网格；主实验固定 6.7 GHz，故 `F=0`。目标 `B` 仅用于 C 的源概率模块；阵列参数、角度及复数权重仅用于解析激励，不能直接传入环境 FNO、FM 状态 lifting 或 AP 条件分支。零通道由代码创建，不读取参考 beam、辅助图或辅助掩膜。C 的 `x_t` 由结构化均值与 beam 条件噪声构成，因而包含间接激励信息；不能声称 FM 网络只学习与 beam 无关的传播规律。频率本身既影响传播又影响激励，允许进入两条物理路径；后续跨频率比较要报告 C 比 A 显式多出频率条件这一差异。

两组共同预处理：原生 beam/radio `128×128`，网络网格 `256×256`；高度按固定 `445 m` 缩放，目标 beam 按 `(clip(B,-300,0)+300)/300` 映射并用 bilinear、`align_corners=False` 上采样。采用固定功率约定，不使用逐图 min–max；核验 Tx 像素、地图朝向和官方配置。网络 `256×256` 输入是对原生网格的上采样，不能描述成新的高分辨率真值。

对 radio 标签，先区分建筑标记 `1000`、floor `−300` 与原生有效支持 `−300<Y<0`；只对有效值做 `(Y+300)/300`。令 `I` 是 bilinear 插值、`m` 是有效掩膜、`u` 是有效标签：训练目标为 `I(m*u)/max(I(m),1e-8)`，仅在 `I(m)>1−1e−6` 的位置计入训练损失。固定此支持及 Haar 完整支持，不让无效值进入边界插值。离线评分使用原生网格目标有效掩膜，推理不读取该掩膜。

## 4. 源分布的具体定义

### 4.1 公共平稳源

令 `C_MS=(C_2+C_8+C_32)/3`，`z_base ~ GP(0,C_MS)`。各 Matérn 算子 `G_l` 使用与现有 PSD 检查采样器相同的 embedding 大小、尺度、谱本征值、FFT 归一化和裁剪约定。三个 `epsilon_l` 与 `z_base` 相互独立；它们是潜在生成噪声，不是真实无线测量。

令 `w_l=1/3`。从相互独立的白噪声生成 `z_uniform = sum_l sqrt(w_l) G_l(epsilon_l)`，使它满足 `GP(0,C_MS)`。A 使用配对实现

```text
x0_A = sqrt(1-lambda^2) * z_base + lambda * z_uniform
```

只要两个分量独立且协方差一致，`x0_A` 的分布严格为 `GP(0,C_MS)`，与原固定 MS 基线等价。该写法允许两组使用相同的基础随机数；在均匀权重下要求与 C 的实现逐元素一致。不得通过同一白噪声生成两个分量后仍声称独立。实际计算开销另记录；配对 A 的实现不应被误称为原单次采样器的最佳运行时间。

### 4.2 C：环境 FNO、解析激励与结构化预测

C 使用一个与 FM 速度网络**独立参数**的 U-shaped FNO + AP：

```text
G = EnvFNO(Tx, H, F)                  # [batch, 2K, 256, 256]
G_k = (G[2k] + i*G[2k+1]) / (100 m) # k=1..K, complex [batch,256,256]
```

首轮 `K=4`，对应 8 个实数输出通道；固定参考长度 `100 m` 仅用于输出量纲和初始化尺度，并不宣称传播距离均为 100 m。实现可复用现有 U-shaped FNO、AP 与 instance normalization 的组件，但需新增**确定性的**环境包装器和 `2K` 复数头；不共享 FM 速度网络权重，不加入 Beam、q、阵列形状、角度、标签或 Beam 条件随机源。若复用原要求 state/time 的模块，状态输入固定为常零、时间固定为 0，不能代表物理传播时间；关闭 dropout。输出是待学习的**潜在传播基**，不直接等同于被观测的复数通道、单条反射或真实 Green 函数。

本节 `G_k` 是环境网络输出的复数场，与第 4.1/4.3 节按尺度标记的 Matérn 滤波算子 `G_l` 是不同对象；代码分别命名 `env_basis` 和 `matern_filter`，避免混淆。

以 3D 阵列中心为坐标原点，参考阵面和方向由官方坐标约定确定。根据配置以 `d=c0/(2f)` 计算中心化阵元位置 `s_n`，用官方码本和功率约定构造复数波束权重 `w_n`，固定 `sum_n |w_n|²=1`。定义物理激励 `a_n=conj(w_n)`。固定四个水平角基方向 `−30°,−10°,10°,30°`；以官方阵列方位变换得到单位向量 `d_k`，首轮使用：

```text
phi_k(s_n,f) = sqrt(element_gain(d_k)) * exp(i*2*pi*f/c0 * dot(d_k,s_n))
c_k = sum_n a_n * phi_k(s_n,f)
u_hat(r) = sum_k G_k(r;Tx,H,f) * c_k
P_hat_mW(r) = P_t_mW * (c0/f/(4*pi))^2 * |u_hat(r)|^2
mu_dBm(r) = 10*log10((P_hat_mW(r)+1e-30 mW)/(1 mW))
mu(r) = (mu_dBm(r)+300)/300
```

四个方向及有限基展开是预设近似；阵元方向增益、极化和几何只按官方参考实现约定处理，不声称能精确覆盖 XL-MIMO 近场或任意天线硬件。`P_t_mW=1` 对应论文的 0 dBm 归一化**须在启动训练前与已发布 beam/label 流程核准**。本机配置文件记录 23 dBm，论文归一化为 0 dBm；应查明它们属于流程中哪个阶段，不能直接把两者当作同一标签功率。相位正负号、共轭、阵面坐标、方向增益和波束归一化必须与官方 Step4/beam 生成代码一致。

验证以目标配置的已发布 beam map 为参照，独立使用官方 LoS 公式和恢复的 `w_n,s_n` 重新计算 `8×8/−14°,0°,+14°` 与 `32×32/−14°,0°,+14°` 六种 beam map；仅比较共同有限、`−200 < B < −20 dB` 的位置，要求每张图 `MAE≤0.1 dB` 且 `P95≤0.5 dB`，并报告最大误差、有效像素数及遮罩规则。该检查使用已知目标配置和可在推理时获得的 beam map，不读取目标 radio 标签；若参考实现的坐标或功率约定导致上述门槛失败，停止训练并修正标定，不能凭假设将该测试视为通过。有限基 `phi_k` 不能替代上述逐阵元 LoS 核验，也不要求四个基单独精确重建全部 beam map。

结构化头在固定场景、频率和阵面条件下对 `a_n` 是线性的，功率非线性为 `|u_hat|²`。频率影响传播和激励，阵元位置变化、互耦或天线方向图变化可能破坏简化假设。相同 `H,Tx,f` 只计算一次 `G`，并复用于同场景各配置；C 的 FM 精修可能破坏最终输出的场线性。即使只有功率标签，`G` 及其复相位仍不可唯一识别；当前 3 个训练角度、`K=4` 时线性激励矩阵秩至多 3，理论上存在未受这些激励约束的方向。

### 4.3 C：Beam 概率图与可微源

从当前目标 beam 的固定预处理输出 `b` 计算中心差分梯度模长 `g_raw=|∇b|`，边界使用单边差分。预处理统计只从训练查询可用的唯一目标 beam 文件计算：取所有有限、严格大于 0 的 `g_raw` 的第 95 百分位，记为 `s_g=max(P95,1e−6)`，保存该数值和训练文件哈希；验证与测试复用它。若没有正梯度则停止并报告。令 `g=clip(g_raw/s_g,0,1)`，不读目标标签。对固定归一化的 `b` 和 `g` 定义：

```text
alpha = softplus(a); beta = softplus(d)
score = alpha*b + beta*g
q = (1-eta)*softmax(score/tau) + eta/N_pix
rho = N_pix*q                         # N_pix = 256*256, not the number of antenna elements
```

softmax 按每个样本的全部 256×256 位置计算。固定 `tau=1`、`eta=0.2`、`lambda=0.5`；初始化 `alpha=beta=1`，即 `a=d=log(exp(1)-1)`。这些是首轮可复现的方案数值，不是已证实最优值。固定 `w_l=1/3` 与长度 `2/8/32`；噪声概率模块新增参数仅 `a,d`，但完整 C 还新增上节的环境 FNO 和复数输出头。

在与原采样器相同的 embedding 网格上，将 256×256 区域的 `rho` 放在对应裁剪位置，其余 embedding 区域填 1；均匀概率时整个权重场等于 1。定义

```text
z_raw = sum_l sqrt(w_l) * G_l(sqrt(rho_embedding) * epsilon_l)
D_phi(p) = sum_l w_l * sum_u psi_l(p-u)^2 * rho_embedding(u)
z_guided(p) = z_raw(p) / sqrt(clamp_min(D_phi(p), 1e-8))
z_B = sqrt(1-lambda^2)*z_base + lambda*z_guided
x0_C = mu + sigma*z_B                # sigma=1, same normalized noise scale as A
```

其中 `psi_l` 是与 `G_l` 同一 FFT 和边界约定下的空间滤波核；`D_phi` 是给定 beam 和参数时的理论点方差，不是根据某次随机样本的实现计算的标准差。按同一 embedding 裁剪输出，计算 `D_phi` 时不可切断对 `a,d` 的梯度。现有 `SourceSampler.transform` 带 `@torch.no_grad()`，因此 C 的加权分支只能复用其固定频谱及约定，必须在可微的 PyTorch FFT 包装器中重新执行滤波；若直接调用该方法，q 到 `a,d` 的梯度会被切断。A 继续沿用原方案。实现必须用单位脉冲、矩阵小样本与蒙特卡洛同时核对 FFT 缩放和 `D_phi`；不得自行将协方差核当成平方根滤波核。仅由 beam 构造 `rho`，不能注入建筑遮挡、目标有效掩膜或目标 radio-map 标签；结构化 `mu` 在整个网格生成，不得使用目标有效掩膜构造推理输入。

均匀 `q=1/N_pix` 时，整个 `rho_embedding=1`，按单位边缘方差约定 `D_phi=1`；复用相同随机数、`sigma=1`，`x0_C−mu=z_B` 必须与 A 的 `x0_A` 逐元素一致。**C 的完整 `x0_C` 因额外结构化均值 mu 不等于 A 的源场**；这项检查只验证噪声部分。条件概率只改变噪声相关结构，不保证源场包含正确反射或更接近目标图。固定 Beam 并改变场景时 C 的 q 不变，但 `mu` 和 FM 速度场均可随场景改变。

对于固定 Beam 和训练后参数，上述噪声 `z_B` 为零均值高斯场；完整源 `x0_C=mu+z_B` 的均值是确定性的 `mu`。若局部方差归一化正确，噪声的单像素边缘方差约为 1；q 所引入的 Beam 信息主要体现在**空间点之间的协方差**。设引导部分协方差为 `C_guided(B)`，则 `Cov(z_B|B)=(1−lambda²)C_MS+lambda² C_guided(B)`；当前 `lambda=0.5` 时，引导分支在此组合中的系数为 `0.25`。不同 Beam 的噪声分布可能很相似，尤其当 q 变化缓慢或归一化抵消局部幅值变化时。若滤波退化为单位算子，逐点方差归一化会把 `sqrt(q)` 完全抵消；不得仅因概率图不同就认定 FM 能读出 Beam。

**噪声分支的不可辨识情形：**若两张预处理 beam 满足 `b2=b1+k`，且未发生 clipping、梯度边界规则相同，则 `q(B1)=q(B2)`，配对随机数时 `z_B` 相同。新 C 还通过阵列配置与解析激励计算 `mu`，因此 q 相同**不代表完整 C 对两个配置一定相同**；整体功率差是否由解析路径保留，需要结合激励计算和结构化预测验证。

## 6. 训练配置与冻结规则

主任务 3 个训练种子 `42,43,44`，每组每种子一个模型，共 6 个模型。相同种子下，A/C 从头构造同一份共享网络初值，隔离 C 新增参数的 RNG；固定每次 update 的场景、配置、白噪声和 `t`，不同种子独立。随机键包含 seed、update、样本槽位及用途；测试随机键还包含 split、完整场景配置和 draw。不能复用旧代码中将所有随机数硬编码为 42 的做法。

沿用当前已记录的工程起点，而非宣称其已是最优：A 保持 AdamW `lr=1e−3`、`betas=(0.9,0.999)`、网络 `weight_decay=1e−5`，`500` update warmup 后 cosine 衰减；总计 `5000` 次成功 optimizer update、global batch `128`。C 的 FM 网络和新增环境 FNO 使用相同学习率、调度与网络 weight decay，从第 1 次起联合更新，不进行额外预训练；`a,d` 使用同一学习率与调度，单独参数组 `weight_decay=0`。两组都是 5000 次成功更新，但 C 每次更新多计算一个环境 FNO，并不等同于相同 FLOPs 或 wall-clock。若显存不足，只调整 microbatch 与梯度累积以保持 global batch，并记录 GPU 与实际组合。FP16 + 项目 `ComplexGradScaler`，FFT、概率图、复数激励、`|u_hat|²`、对数与局部方差保持 FP32；EMA 与条件 dropout 关闭。

```text
t ~ Uniform(0,1)
xt = (1-t)*x0 + t*y
u  = y-x0
loss_A = masked_FM_MSE(v_A(xt,t,c_A),u)
       + 0.05*Haar1_A + 0.05*Haar2_A
loss_C = masked_FM_MSE(v_C(xt,t,c_C),u)
       + 0.05*Haar1_C + 0.05*Haar2_C + 0.1*masked_L1(mu,y)
```

`c_A=[Tx,H,B,0,0,0]` 原样保留，`c_C=[Tx,H,F,0,0,0]`，主任务中 `F=0`。两个 Haar 损失作用在速度误差上，先对误差做 2× average pooling，使用旧 `training/detail_losses.py` 中的完整有效支持和各自有效项计数；跨 microbatch 按整体有效数量归一化。`masked_L1(mu,y)` 在与 FM 相同的训练有效支持上计算，权重 `0.1` 是首轮固定假设，作用是直接约束结构化均值，不能解出真实复数相位。C 的可训练源采用可微路径，对 `xt` 和 `u` 中的 `x0` 依赖均保留梯度；对 `mu`、`q`、`D_phi` 或 `x0` 不得无意 `detach`。环境复数输出头使用非零 Xavier 初始化，避免 `u_hat=0` 时功率平方头梯度完全为零；必须在真实样本上检查 `mu` 与梯度有限。A 不需要源参数梯度。训练的 `xt` 按标准 FM 路径包含目标场成分，这是训练监督的一部分；推理只能由源场迭代得到状态，不能将训练标签注入推理。两组一律不加载旧 checkpoint。

每 `250` 次成功更新保存并验证，验证所有 `240` 条 seen-config 查询，Euler `NFE=8`、每查询一个固定 draw；以原生网格每场景/查询 MAE 宏平均最小选择 checkpoint，完全相同时选较早者。只使用该验证指标选择，每种子单独选一个 checkpoint，然后冻结。不得用 32×32、留出角度或测试标签选超参数或 checkpoint。

## 7. 推理、指标与统计

冻结后，每个 seed 在每个测试查询上使用 Euler `NFE=8`、4 次配对固定随机 draw；A/C 共享 `z_base`、各 `epsilon_l` 随机流。每次先在 256×256 网格生成，bilinear 下采样到原生 `128×128`，反归一化 `dB=300*pred−300`，不夹紧；报告输出落在 `[-300,0] dB` 外的比例。

主要指标为每图有效像素的 MAE（dB，越低越好）。先分别计算每个 draw 与查询，再对 draw、3 个对应角度、scene 等权平均；不得挑选 best-of-4。次要指标：RMSE（dB）、PSNR（data range `300 dB`、每图有效像素 MSE）、SSIM（`11×11` Gaussian window、`σ=1.5`、`K1=0.01`、`K2=0.03`、data range `300 dB`，只算完全有效的窗口；无有效窗口记缺失并报告数量）。所有组使用同一 target 有效支持。

为了观察建筑附近细节，在原生高度图 `H>0` 上取建筑占据区，以 Chebyshev 半径 3 像素膨胀，减去建筑本身，再与标签有效支持相交，计算区域 MAE。报告无有效边界像素的样本数。该指标是建筑附近误差代理，不能单独证明特定反射路径被恢复。附加图按场景数字 ID 升序排列冻结的 160 个测试场景，固定选择第 1、80、160 位，并统一展示主测试中的 `32×32/0°`；不能根据 A/C 好坏事后挑例。

对每个 seed 和 scene 先按对应角度、draw 平均，得到 `delta_scene_seed=MAE_C−MAE_A`；分别报告 3 个 seed，再对 seed 平均后在 160 个测试场景上做 10,000 次有放回配对 bootstrap，给出 2.5%/97.5% 分位区间；“接近 A”的单侧参考使用同一 bootstrap 分布的 95% 上分位。分别报告角度与联合变化的次要结果，不用它们倒选主结论。160 个测试场景由现有资源决定，本计划没有先验效应量和正式功效计算，报告区间宽度而不声称有足够统计功效。

**C 的 Beam 噪声路径诊断：**在验证集的 `8×8/−14°,0°,+14°` 查询上固定场景、Tx、网络权重和配对噪声，**保持解析激励、结构化均值 mu、原目标和速度条件均为正确配置**，仅将进入源概率模块的 Beam 按 `−14→+14`、`0→−14`、`+14→0` 错配；离线报告正确 q 与错配 q 的 MAE 差及最终预测变化。另保持 `mu` 与解析激励不变，将 q 强制为均匀分布重复推理。两项均不参与 checkpoint 选择；它们只检查噪声通路是否有作用，错配和强制均匀可能偏离训练分布，不能单凭变化证明物理解耦。冻结方法后可按相同映射描述主测试情形，预先记录所有结果。

仅观察概率图不够：对验证用三个 Beam 和固定训练后参数，各使用 256 个配对噪声 draw，在固定的 16×16 坐标子集及横/纵位移 `1、4、16` 像素上估计 `z_B` 的局部协方差，报告 Beam 之间的协方差差异及 Monte Carlo 不确定性，并对照均匀 q。该诊断不使用 radio 标签，也不用于挑选测试结果；它衡量噪声中是否保留可见的统计差异，不保证 FM 已正确解码这些差异。

**结构化分支诊断：**对每个选定 checkpoint，单独将 `mu` 下采样并按与 A 相同的有效支持计分，报告 C 的结构化预测与最终 FM 预测；mu 只来自模型和目标配置，不读取真实目标。固定 `H,Tx,f` 更换阵列或角度，检查环境 FNO 的 `G` 是否不变，随后报告解析激励、`mu` 和最终输出如何变化。对固定阵面与环境，用未重新单位化的复数激励向量检验 `u_hat(a1+a2)=u_hat(a1)+u_hat(a2)`；这是结构自检，不能当成真实场精度证明，也不对功率或 FM 最终输出套用线性叠加。

以三个训练角度形成 `3×K` 的复数激励矩阵，仅使用已知配置（不读 radio 标签）记录其奇异值及秩；计算每个 32×32 目标激励向量到训练激励向量复线性张成空间的最小相对残差。该诊断量化当前基与训练查询的覆盖，但不证明复数传播基可由功率标签唯一识别；`K=4`、三角度的矩阵秩最多为 3。后续若扩展训练角度，A、C 均须在同一新协议下重新训练，不能只对 C 增加标签后与旧 A 声称同协议比较。

## 9. 可能结果与解释

1. **C 稳定优于 A：**说明该数据和协议下结构化环境/激励、Beam 引导源及 FM 的整体 C 方案表现更好；不能单独归因于噪声、物理结构或去掉直接条件，也不能声称恢复了真实传播路径。
